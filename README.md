🎬 MovieIQ — Predictive Analytics on Film Success

«Where Data Meets the Silver Screen.»

MovieIQ is an interactive Movie Analytics and Machine Learning Dashboard built using Python and Streamlit. The project explores the factors associated with movie success and uses a Random Forest Classification model to predict whether a movie is likely to be successful based on selected performance indicators.

A movie is classified as successful when its revenue is greater than its budget.

---

🌟 Project Overview

The film industry involves significant financial investment, and predicting the potential success of a movie can help stakeholders make more informed decisions.

MovieIQ analyzes movie data using Exploratory Data Analysis (EDA), Statistical Testing, and Machine Learning to understand the relationship between movie characteristics and financial success.

The project provides an interactive dashboard where users can:

- 📊 Explore movie performance data
- 🎭 Analyze movie genres and success trends
- 💰 Explore the relationship between budget and revenue
- ⭐ Investigate the impact of popularity and audience ratings
- 📈 View statistical test results
- 🤖 Predict movie success using a Random Forest Classifier
- 🔍 Explore important features influencing predictions
- 🎚️ Filter movies based on genre and minimum vote average

---

🎯 Project Objective

The main objective of MovieIQ is to analyze historical movie data and build a machine learning model that predicts whether a movie will be successful based on selected features.

The project follows a complete data analytics and machine learning workflow:

Data Collection → Data Cleaning → Exploratory Data Analysis → Statistical Testing → Machine Learning → Model Evaluation → Interactive Dashboard

---

🏆 Definition of Movie Success

For this project, a movie is considered successful when:

Revenue > Budget

The target variable is:

- "1" → Successful Movie
- "0" → Unsuccessful Movie

This makes the project a binary classification problem.

---

📊 Dataset

The project uses a movie dataset containing information related to movie performance and characteristics.

Key variables include:

Feature| Description
"budget"| Production budget of the movie
"revenue"| Revenue generated by the movie
"popularity"| Popularity score
"runtime"| Duration of the movie
"vote_average"| Average audience rating
"title"| Movie title
"genres"| Genre or genres associated with the movie

The target variable "success" is created based on the relationship between revenue and budget.

---

🔎 Exploratory Data Analysis

MovieIQ performs several exploratory analyses to identify patterns and relationships in the dataset.

The analysis includes:

- Budget vs. Revenue analysis
- Genre distribution
- Genre-wise success trends
- Relationship between popularity and movie success
- Relationship between runtime and movie success
- Relationship between vote average and movie success
- Correlation analysis of numerical variables

These visualizations help identify patterns that may contribute to movie success.

---

🧪 Statistical Analysis

The project applies statistical tests to investigate whether observed differences and relationships are statistically significant.

T-Test

A T-Test is used to examine whether a selected numerical feature differs significantly between successful and unsuccessful movies.

Chi-Square Test

A Chi-Square test is used to investigate whether movie genre and success are statistically associated.

The project uses p-values to determine statistical significance based on the selected significance threshold.

---

🤖 Machine Learning Model

Random Forest Classifier

MovieIQ uses a Random Forest Classifier to predict movie success.

Random Forest is an ensemble machine learning algorithm that combines the predictions of multiple decision trees to produce a final classification.

The model is trained using selected movie performance features and evaluated on a separate test dataset.

Model Evaluation

The model is evaluated using:

- Accuracy
- Precision
- Recall
- Confusion Matrix
- Feature Importance

Feature importance is also analyzed to understand which variables contribute most to the model's predictions.

⚠️ Limitations

Movie success depends on many factors that may not be captured in the dataset, such as:

- Marketing and promotional expenditure
- Cast and director popularity
- Production quality
- Competition from other releases
- Release timing
- Audience preferences
- Critical reviews
- Distribution strategy

Therefore, the model's prediction should be considered an analytical estimate rather than a guaranteed prediction of future movie performance.
