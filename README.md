# 🎬 MovieIQ — Where Data Meets the Silver Screen

> **Movie Analytics • Data Visualization • Statistical Analysis • Machine Learning • Predictive Analytics**

MovieIQ is an interactive **Movie Data Analytics and Machine Learning Dashboard** built using Python and Streamlit. The project analyzes movie performance, financial trends, genre patterns, audience ratings, popularity, and other key performance indicators to discover patterns associated with movie success.

The dashboard combines **Data Analytics, Exploratory Data Analysis (EDA), Statistical Analysis, Machine Learning, and Interactive Visualization** into a single platform.

> 🎥 **Explore movie performance. Discover genre trends. Analyze box-office economics. Predict movie success.**

---

## 🌟 Project Overview

The film industry involves significant financial investment, and understanding the factors associated with movie performance can support better data-driven decision-making.

MovieIQ provides an interactive platform to explore a dataset of **2,000 movies** and analyze important movie performance indicators, including:

- 💰 Production Budget
- 💵 Revenue
- 📈 Profit
- 🔥 Popularity
- ⏱️ Runtime
- ⭐ Average Audience Rating
- 🎭 Genre

The project also applies Machine Learning techniques to predict movie success and provides interactive insights through a Streamlit dashboard.

For this project, a movie is classified as **successful when its revenue is greater than its budget**.

---

## 🎯 Project Objectives

The main objectives of MovieIQ are to:

- Analyze historical movie performance data.

## 📌 Definition of Movie Success

For this project, a movie is considered **successful** when:

Revenue > Budget

The target variable is defined as:

- Success = 1 → Successful Movie
- Success = 0 → Unsuccessful Movie

Therefore, the movie success prediction task is treated as a **binary classification problem**.

---

## 📊 Dataset

The MovieIQ project uses a dataset containing **2,000 movie records**.

The core dataset includes the following columns:

| Column | Description |
|---|---|
| `budget` | Production budget of the movie |
| `revenue` | Revenue generated by the movie |
| `popularity` | Popularity score associated with the movie |
| `runtime` | Runtime of the movie in minutes |
| `vote_average` | Average audience rating |
| `title` | Movie title |
| `genres` | Genre information associated with the movie |

Additional derived variables such as **Profit**, **Success**, and processed **Genre** information are used during the analysis.

# 🧹 Data Quality Analysis

Before performing analysis and Machine Learning, the dataset is checked for data quality issues.

The dashboard examines:

- Missing values
- Zero budget values
- Zero revenue values

The current dataset contains **no missing values in the displayed dataset fields** and reports **zero movies with zero budget and zero revenue**.

Zero values in financial fields can sometimes represent unavailable or missing financial information rather than genuine zero values. Therefore, such records should be reviewed carefully before analysis and Machine Learning model training.

# 🤖 Machine Learning

## Random Forest Classifier

MovieIQ uses a **Random Forest Classifier** to predict movie success.

Random Forest is an ensemble Machine Learning algorithm that combines multiple decision trees to produce a final prediction.

The model uses selected movie performance features to predict the binary target variable:

- Success = 1 → Successful Movie
- Success = 0 → Unsuccessful Movie

### Model Evaluation

The predictive modelling workflow evaluates the model using metrics such as:

- Accuracy
- Precision
- Recall
- Confusion Matrix
- Feature Importance

The project also includes model comparison to evaluate predictive performance.

---

# 📈 Feature Importance

The Random Forest model provides feature importance values to show the relative usefulness of different input variables in making predictions.

The dashboard visualizes the importance of:

- Budget
- Popularity
- Runtime
- Vote Average

In the displayed model analysis, **budget is identified as the most important feature**, with an importance score of approximately **0.2631**.

Feature importance should be interpreted as a measure of model usefulness rather than proof that a feature directly causes movie success.

## ⚠️ Limitations

Movie success depends on many factors that may not be included in the current dataset.

Some limitations of the project include:

- The analysis is based on a dataset containing 2,000 movie records.
- The dataset may not represent the complete global movie industry.
- Movie success is defined using the relationship between revenue and budget.
- Marketing and promotional expenditure is not included.
- Cast and director influence are not considered.
- Production studio and distribution strategy are not included.
- Release timing and seasonality are not considered.
- Audience preferences and social media trends are not captured.
- Machine Learning predictions depend on the quality and characteristics of the available dataset.
- Feature importance indicates model usefulness but does not establish causal relationships.

Therefore, MovieIQ predictions should be considered **data-driven estimates rather than guaranteed predictions of future movie success**.
